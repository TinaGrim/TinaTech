# Project Screenshot Checklist

Drop each screenshot into **`public/screenshots/`** (exactly this folder — the site loads
them from there). Use the exact filename shown; filenames are case-sensitive on most
deployment hosts, so keep everything **lowercase `.png`**. A matching filename makes the
real screenshot appear automatically — no code changes needed.

## Format rules (all projects)

| Rule | Value |
| --- | --- |
| Extension | `.png` only — exact lowercase (`.PNG` / `.jpg` will be silently ignored) |
| Recommended size | ~1600 × 960 px (**~5:3 landscape**) |
| File-size budget | under 500 KB (compress at tinypng.com if larger) |
| Cropping | Images fill the card and are **cropped from the center** — keep the important content centered; edges may be trimmed |

> If a file is missing, unreadable, or misnamed, the card quietly shows a stock photo
> instead — so if you still see stock imagery after adding a file, re-check spelling,
> extension case, and location.

## Capture how-to

- **Linux:** `Flameshot` or ` gnome-screenshot -w` (capture window)
- **Windows:** `Win + Shift + S` → Window snip
- **macOS:** `Cmd + Shift + 4`, then `Space` to grab a window

Capture the app window only (no desktop), at normal 100% zoom, in light theme where applicable.
